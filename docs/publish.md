# Publish on GitHub

Create an empty **public** repository named `ron-raisch-data-science-skills` under your account. Do not initialize a README, license or gitignore: they are already included here.

[Open GitHub's prefilled repository form](https://github.com/new?name=ron-raisch-data-science-skills&description=Practical%20research%20skills%20for%20data%20scientists%20and%20AI%20agents&visibility=public)

If you received a Git bundle:

```bash
git clone ron-raisch-data-science-skills.bundle ron-raisch-data-science-skills
cd ron-raisch-data-science-skills
git remote remove origin
git remote add origin https://github.com/YOUR_USERNAME/ron-raisch-data-science-skills.git
git push -u origin main
```

Replace YOUR_USERNAME with your GitHub account. A bundle contains the complete local Git history and runnable source. No remote repository or remote access is claimed by preparing it. After publishing, optionally tag a release, review Actions results, and share selected skills rather than installing the entire collection by default.
