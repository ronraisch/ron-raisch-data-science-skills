# Runtime evidence

Use the full checkout's tools/experiment_verification package for executable checks. Never populate observed values from expected values. Capture after framework overrides. runtime.json has schema_version, run_id, spec_sha256, observations, artifacts, predictions, evaluation_split. Each observation has value, source (hook/function), stage (start/end), kind (runtime/manual). Only runtime-kind evidence can be fully verified by the generic comparator; manual evidence is partial. No self-reported JSON proves execution independently.

Required observed categories: preprocessing, model, checkpoint, parameters, optimizer, scheduler, hyperparameters, training, metric, environment. Include an explicit observed null when a scheduler/checkpoint does not apply. Missing observation is unverifiable, even if the intent is null. Record actual objects, checkpoint load results, trainable names and completed steps. Artifact entries contain path and SHA-256. Predictions CSV uses id,target,prediction for the built-in accuracy or MAE adapter. Dataset CSV has id,group,x,target; split JSON maps train/validation/test to sample-ID lists. Adapt these schemas explicitly for another domain; do not pretend this tabular adapter verifies arbitrary ML pipelines.

Check raw data/split hashes and ID/group overlap, runtime equality, artifacts and recomputed metrics. Unsupported metrics require an audited adapter. Wrong identity or contradictory observations fail. Missing evidence is unverifiable; partial manual observations remain partial. Run the comparator preflight for input checks and postflight for completed evidence. Block result promotion if anything required is not verified.
