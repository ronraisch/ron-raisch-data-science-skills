# EDA

Synthetic sensor study; generated by examples/demo.py, seed 17. Independent unit: sensor group (two readings each). Train/validation/test IDs are in splits.json; all 180 rows have unique IDs. Group splits are isolated by construction and checked by preflight. Labels are complete synthetic binary classes. No missing values are generated. The x field is available before the target.

Training n=100, mean x=0.127041, SD=1.096420, positive fraction=0.470. See eda.json for exact aggregates and input hashes, figures/eda.svg for distribution. The test labels were not used for EDA or model choice.

Observation: training data spans both sides of zero and has both classes. Hypothesis H1: a fitted linear classifier improves over majority class. Rival: the majority rate alone explains apparent performance. Measurement and label-noise explanations remain plausible near the boundary. Synthetic data cannot establish sensor-domain validity or external bias. Group assignment is sequential in generated IDs but random draws use one seeded stream; no real temporal generalization is claimed.

Reproduce: python -m examples.demo --output NEW_DIRECTORY. Raw data is never transformed in place.
