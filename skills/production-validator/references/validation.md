# Standalone validator adapter

`python -m tools.production.validator POLICY.json OUTPUT/validator.py` embeds a stdlib-only CV adapter and approved policy. The generated module imports no research code. Invoke `validate(output_pred, output_test)` with directory paths; successful return is None. AssertionError means failure. Other exceptions also mean failure. Never catch exceptions and call them success. Python -O is prohibited because it disables assertions.

Policy schema_version 1: task detection/segmentation; strategy ground_truth/reference/hybrid/invariants; classes; files mapping actual sample IDs to `{prediction: relative-team-path, test: relative-reference-path}`; quality bounds; reference criteria; detection score_threshold. Every file must exist. Prediction JSON `{id, prediction}`; test JSON `{id, truth, reference}` with required fields determined by strategy. This is an example adapter with explicit layout mapping, not a mandatory internal MLOps format. Use established conventions and add a reviewed parser for other output formats.

Detection: axis-aligned continuous xyxy boxes, class name, score in [0,1]; truth omits score. Class-specific greedy score-ranked one-to-one matching at IoU >= .5. All-point interpolated AP, macro over GT-present classes; precision/recall at fixed score threshold; false alarms per sample. No crowd/void/partial-annotation or OBB semantics are implied. Reference comparison requires equal count, class-compatible box IoU and score tolerance; reordering is allowed. More complex matching requires a reviewed task-specific adapter.

Segmentation: nonempty rectangular dense integer label masks; same shape as truth/reference. Macro IoU over union-present declared classes; reference pixel agreement. No implicit void-label policy. Structural, finite, label and shape checks always apply. An invariants-only policy certifies only these structural invariants; add required task-specific metamorphic properties and their negative controls explicitly. Do not claim this adapter tests unimplemented invariants.

Approval fields: by, role (research-lead/product-stakeholder), reference, policy_sha256. Hash the exact policy excluding approval with component canonical(). This binds recorded approval to policy content; it does not authenticate the approver. Toy approvals in examples are explicitly demonstrative, not operational authorization.

Quality bounds are inclusive minimum/maximum. Metrics needing positives fail if labels contain none. Reference-only can represent an approved empty detection sample, but an empty dataset never passes. Additional samples are ignored by this fixed declared sample mapping; all declared samples are mandatory. Tests must cover each required class/edge case, not only high-score examples.

Optional approved `metamorphic` pairs name base/transformed sample IDs and relation horizontal_flip or duplicate_input. Detection pairs declare min_box_iou, score_atol and width for flips; segmentation declares min_pixel_agreement. Validation derives the transformed expected output from the base output, without ground truth or exact external references. Both samples must exist. Add task-specific relations in reviewed standalone code with positive/negative tests.
