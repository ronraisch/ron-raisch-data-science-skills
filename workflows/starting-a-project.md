# Starting A Project

research-grill → literature-review → eda → hypothesis-generation → research-wayfinder

1. Follow [research-grill](../skills/research-grill/SKILL.md). Save brief.md and project.json. Pass the saved outputs and evidence paths to the next step; do not rely on chat memory.
2. Follow [literature-review](../skills/literature-review/SKILL.md). Save literature.md, sources/search-log.csv and sources/evidence.csv. Pass the saved outputs and evidence paths to the next step; do not rely on chat memory.
3. Follow [eda](../skills/eda/SKILL.md). Save eda.md, reproducible script, data hashes and figures. Pass the saved outputs and evidence paths to the next step; do not rely on chat memory.
4. Follow [hypothesis-generation](../skills/hypothesis-generation/SKILL.md). Save hypotheses.json with rival predictions. Pass the saved outputs and evidence paths to the next step; do not rely on chat memory.
5. Follow [research-wayfinder](../skills/research-wayfinder/SKILL.md). Save roadmap.md, decisions.md and next_experiments. Pass the saved outputs and evidence paths to the next step; do not rely on chat memory.

Gate: unresolved missing evidence stays explicit. Scientific conclusions require valid comparable runs; a plan or preflight alone cannot verify execution. Offline use records local-corpus and tooling limits.

Define the useful pipeline hierarchy with component-design before freezing the first experiment. Preserve stable responsibilities; do not enumerate every layer.
