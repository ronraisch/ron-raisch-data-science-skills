# Skill compositions

Skills can be used alone or chained by passing durable files. Do not force every small study through every workflow.

- [Starting a project](starting-a-project.md): question → literature → EDA → hypotheses → roadmap.
- [Running an experiment](running-an-experiment.md): design → verification plan/preflight → execution with live/postflight checks → comparison.
- [Investigating failures](investigating-failures.md): error evidence → rival explanations → discriminating experiment.
- [Completing a milestone](completing-a-milestone.md): comparison → evidence summary → process lessons → internal article.
- [Pausing/resuming](pausing-and-resuming.md): handoff → reconstructed current evidence → revised roadmap.

The complete CPU example demonstrates these transitions with actual artifacts. Verification is an ongoing activity, not a ceremonial step before training. Read docs/records.md for state transitions and comparison eligibility.

- [Production transfer](production-transfer.md): approved inference → isolated notebook parity → separately approved production validation.
